Para anotar leituras feitas à mão (pluviômetro manual, anemômetro ou estimativa visual) enquanto não há registro automático. Os registros ficam só neste aparelho e navegador. Não anote nomes, telefones ou documentos de moradores. Este modelo é um ponto de partida: combine com sua chefia o horário e o local fixos das leituras, para os dados ficarem comparáveis. Limpar os dados do navegador apaga tudo: use Exportar para backup.
